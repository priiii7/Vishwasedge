# API Reference

Base URL (local): `http://localhost:8000`. Interactive OpenAPI docs at `/docs` (Swagger UI, auto-generated by FastAPI) once the backend is running.

## Auth

### `POST /api/v1/auth/login`
```json
{"username": "operator", "password": "changeme123"}
```
→ `{"access_token": "...", "token_type": "bearer", "role": "admin"}`

### `GET /api/v1/auth/me`
Header: `Authorization: Bearer <token>`
→ `{"username": "operator", "role": "admin", "permissions": ["read","write","query","manage_users"]}`

Alternative to JWT: header `X-API-Key: <DEFAULT_API_KEY from .env>`.

## Documents

### `POST /api/v1/documents/upload` (multipart/form-data)
Fields: `file` (PDF/DOCX/TXT/MD), `source`, `category`.
→ `{"job_id": "...", "status": "completed", "estimated_chunks": 12}`

### `GET /api/v1/documents/status/{job_id}`
→ `{"job_id": "...", "status": "completed", "chunks_indexed": 12, "errors": []}`

### `GET /api/v1/documents/list`
→ array of ingested documents.

## Query

### `POST /api/v1/query`
```json
{
  "query": "What is the safe operating pressure for well W-123?",
  "context": {"well_id": "W-123"},
  "options": {"stream": false, "include_explanation": true, "max_docs": 5}
}
```
→
```json
{
  "response": "...",
  "confidence": 0.82,
  "tier_used": "fast",
  "latency_ms": 41.2,
  "warnings": [],
  "explanation": {
    "confidence_score": 0.82,
    "calibration": "medium",
    "sources": [{"chunk_id": "...", "source": "...", "confidence": 0.79, "reason": "...", "excerpt": "..."}],
    "token_saliency": [{"token": "safe", "importance": 0.12}],
    "alternate_paths": ["..."],
    "explanation_latency_ms": 1.8
  },
  "retrieval_metadata": {
    "num_docs_considered": 12,
    "num_docs_used": 3,
    "reranker_used": true,
    "latency_ms": 18.4,
    "degradation_strategy": null
  }
}
```

### `GET /api/v1/stream?query=...&context=%7B%7D&token=<jwt>`
Server-Sent Events. `EventSource` can't send an `Authorization` header, so the JWT (or `apiKey`) is passed as a query param.
```
data: {"type":"token","content":"The "}
data: {"type":"explanation","content":{...}}
data: {"type":"done","content":{"confidence":0.82,"tier_used":"fast","latency_ms":41.2}}
```

## System

- `GET /api/v1/system/models` — which embedding/reranker/LLM backends are actually active vs. running in fallback mode.
- `GET /health` — liveness.
- `GET /ready` — readiness (DB, cache, disk, vector store checks).
- `GET /metrics` — Prometheus exposition format.
